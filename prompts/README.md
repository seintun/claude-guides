# prompts

Prompts that the `/prompt` skill writes for other projects land here, one folder per project:
`prompts/<project>/<YYYY-MM-DD>-<short-name>.md`.

Everything in this folder except this README is git-ignored. Prompts can carry a project's private details, so
they never reach this repository or the project's own. To keep a prompt for good, copy the parts worth keeping
into that project's plan or decision log (see [wiki/records.md](../wiki/records.md)).

To reuse one, start a fresh session in the project and say: "run the prompt in <path to the file>".
