# private

Notes, plans and research that are not part of the guide: work on a personal harness, another project, or anything with private details.

Everything in this folder except this README is git-ignored, so nothing here reaches the public repository. If a note turns into guide material, rewrite it in general terms and move it to `docs/`, `research/` or the playbook, then run `python3 -I tools/check_privacy.py`.
