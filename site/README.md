# site

| File | What it is |
|---|---|
| `index.html` | **Open this one locally.** The teaching page as a full HTML document. Generated by `tools/build_standalone.py`; do not edit by hand |
| `orchestrating-claude.html` | The teaching page's source, version 17, last updated 2026-10-27, as an artifact body. Live at https://claude.ai/artifact/8q1jNZyZ1HTjDBvqgBWMLq (private to its owner until shared) |
| `history/orchestrating-claude-v11.html` | Version 11, the baseline the UX issue was written against |

The source is an artifact body: no doctype and no html, head or body tags, because the claude.ai viewer wraps it. Opened on its own, it breaks. The browser renders it in quirks mode, and dev servers such as VS Code Live Server inject their reload script before every `</svg>`, which blanks the figures.

To view the page, open `index.html` directly or through any local server. It wraps the source the way the viewer does.

After editing the source, run this to refresh `index.html`:

```bash
python3 -I tools/build_standalone.py
```

`checks/static.sh` fails while `index.html` is stale. Before editing the source, read the page rules in [AGENTS.md](../AGENTS.md).
